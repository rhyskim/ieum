# Task: archive (아카이브 타임라인 + 이모지 리액션)

- 브랜치: `feat/archive` / worktree: `.worktrees/archive`
- 대상: backend + mobile
- 선행: answer(머지됨)

## 목표
공개된 답변에 이모지 리액션을 달고 취소할 수 있고, 지난 질문과 답변을 날짜순 타임라인으로 볼 수 있다.

## 범위
- Flyway 새 버전: `answer_reactions`에 `UNIQUE(answer_id, user_id, emoji_code)` 추가(기존 중복 정리 포함). 음성 리액션 행(`reaction_type`)과 충돌하지 않도록 이모지 행에만 적용되는 부분 유니크 인덱스로 설계하고 근거를 PR에 적는다.
- API: 리액션 달기 `PUT`(이미 있으면 그대로, `INSERT ... ON CONFLICT DO NOTHING`), 취소 `DELETE`(없으면 그대로). 이모지 5종(LOVE, TOUCHED, THANKS, FUNNY, HUG). 한 사람이 한 답변에 여러 종류 가능, 본인 답변에도 가능.
- 서버 권한: 공개 전(LOCKED) 답변에는 거절, 유효 멤버만, REVEALED_TIMEOUT이면 본인이 답변을 마친 경우만. 탈퇴 유예·탈퇴 사용자의 답변과 리액션은 보이되 작성자 표기는 "탈퇴한 사용자"(보는 사람이 정한 호칭이 있으면 그것).
- 타임라인 API: `cycle_date` 내림차순 커서(키셋) 페이징(id 보조 정렬), 각 항목에 질문·공개 상태·내가 답했는지·리액션 집계(종류별 개수, 내가 단 것). LOCKED 항목의 타인 본문은 내리지 않는다(서버 마스킹 유지).
- 리액션 목록 API: 종류별로 누가 달았는지(호칭 표기 규칙 동일).
- 모바일: 답변 카드 하단 이모지 바(앱이 화면 상태를 보고 PUT 또는 DELETE를 고름), 리액션을 탭하면 단 사람 목록, 아카이브(타임라인) 화면. 본문 18sp 이상, 터치 48dp 이상, 아이콘에는 한글 라벨. 디자인 톤(바랜 종이 질감)은 이번 범위 밖이며 기본 테마를 쓴다.

## 범위 밖
음성 리액션, 리액션 알림, 검색·카테고리 필터, 디자인 톤 적용.

## 수용 기준 (테스트로 표현)
- [ ] 같은 사람이 같은 이모지를 여러 번·동시에 PUT해도 1건(동시성 테스트), DELETE 반복도 오류 없이 멱등.
- [ ] 한 사람이 한 답변에 서로 다른 종류를 여럿 달 수 있다.
- [ ] LOCKED 답변에는 PUT이 거절되고, TIMEOUT 상태에서 본인이 답하지 않았으면 거절된다. 비멤버·유예 사용자는 거절된다.
- [ ] 타임라인은 새 항목이 생겨도 중복·누락 없이 다음 페이지를 이어 받는다(커서). LOCKED 항목에 타인 본문이 없다.
- [ ] 탈퇴한 사용자의 리액션은 "탈퇴한 사용자"로 나오고, 보는 사람이 정한 호칭이 있으면 그 호칭이 나온다.
- [ ] 마이그레이션이 기존 중복 데이터가 있어도 실패하지 않는다.
