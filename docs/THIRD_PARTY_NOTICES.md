# 서드파티 고지

앱에 포함해 배포하는 글꼴의 저작권자와 라이선스를 적는다. 라이선스 전문은 `mobile/assets/licenses/`에 있고 앱의 설정 > 오픈소스 라이선스 화면에서도 볼 수 있다. 패키지(pub) 라이선스는 Flutter가 빌드 시 자동 수집해 같은 화면에 보여 준다.

모든 글꼴은 SIL Open Font License 1.1(OFL)이며 상업 이용과 앱 번들 포함이 가능하다. 원본 파일을 수정하지 않고 그대로 포함한다(런타임 다운로드 없음).

| 글꼴 | 용도 | 저작권 | 라이선스 | 출처 |
|---|---|---|---|---|
| Gaegu | 제목(임시 적용) | Copyright 2018 The Gaegu Project Authors | OFL 1.1 | https://fonts.google.com/specimen/Gaegu · https://github.com/google/fonts/tree/main/ofl/gaegu |
| Gowun Dodum (고운돋움) | 본문(임시 적용) | Copyright 2021 The Gowun Dodum Project Authors (https://github.com/yangheeryu/Gowun-Dodum) | OFL 1.1 | https://fonts.google.com/specimen/Gowun+Dodum · https://github.com/google/fonts/tree/main/ofl/gowundodum |

글꼴은 오너의 최종 선택 전까지 임시 적용이며, 선택이 바뀌면 이 표와 `mobile/assets/`를 함께 갱신한다.
