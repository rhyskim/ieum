# ADR-0006: 질문 은행과 일일 질문 배정

- 상태: **확정** (2026-11-18, 오너 답 + Root 가정은 "Root 가정" 절에 명시)
- 날짜: 2026-11-18
- 학습 노트(옵시디언): `개발/Ieum/학습/0008-소셜로그인-검증과-일일질문-배정.md` (Part B)

## 맥락
매일 그룹마다 질문 1개를 배정한다(`daily_questions`, `UNIQUE(group_id, cycle_date)`, V1에 있음). 서버가 여러 대이거나 꺼져 있어도 그룹당 하루 1개가 정확히 생겨야 한다.

## 오너의 답
| # | 답 | 판정 |
|---|---|---|
| B-1 | ShedLock으로 서버 간 중복 방지(서버 공유 메모리) | △ 방향 맞음. 락은 DB 행이고 만료가 있어 UNIQUE가 최종 방어선 |
| B-2 | 순서대로, 질문 1000개 직접 작성, 스페셜 데이는 고도화 | ○ |
| B-3 | 은행은 안 바닥남, 놓치면 복구 시 전송. 전송 기록은 따로? | ○ 기록은 로그가 아니라 `daily_questions` 행 |
| 후속 | 19시 이후 만든 그룹은 **그 날 바로 배정** | 확정 |

## 최종 결정
1. 배정은 **19시 이후 5분마다 도는 보정형 작업**이다: 오늘(cycle_date) 질문이 없는 ACTIVE 그룹을 찾아 `INSERT ... ON CONFLICT DO NOTHING`으로 채운다. ShedLock은 불필요한 중복 실행을 줄이고, UNIQUE는 중복을 불가능하게 한다.
2. 푸시는 배정이 **실제로 새 행을 만들었을 때만**(영향 행 1) 커밋 후 비동기로 보낸다(ADR-0004).
3. 질문 선택: 그룹이 지금까지 받은 질문 수 + 1번째(`sequence_order` 순서). 그룹 생성 직후 첫 질문은 그 날 바로 배정한다(오너 확정).
4. 공개 시각은 항상 배정 날짜 다음날 17:00(KST) 그대로다. 늦게 배정돼도 연장하지 않는다(오너 확정).
5. 사이클은 19:00~다음날 19:00이다. 누락 보정은 현재 사이클에 대해서만 하고, 지난 사이클은 건너뛴다.
6. 남은 질문 수가 임계치(예: 30개) 아래면 경고 로그를 남긴다. 은행이 비면 배정을 건너뛰고 오류 로그를 남긴다(서비스 중단 없음).
7. **Root 가정(승인 대기)**: 오너가 쓴 질문은 레포의 CSV 파일에서 Flyway 버전 마이그레이션으로 적재한다(적용된 마이그레이션은 수정 불가이므로 추가 질문은 새 버전 파일). 개발용으로는 샘플 질문 약 30개만 넣는다. 스페셜 데이(멤버가 만든 질문)는 후속 기능이다.

## 결과·후속 작업
작업지시서 `docs/tasks/question.md`. 스키마 변경은 질문 적재 마이그레이션 외에 없을 수 있다(Worker가 확인해 보고).
