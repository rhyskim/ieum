# Task: theme (종이 질감 테마, 글자 크기 조절, 탭 구조)

- 브랜치: `feat/theme` / worktree: `.worktrees/theme`
- 대상: mobile (백엔드 변경 없음)
- 선행: answer(머지됨). archive와 병행 가능(화면 파일 충돌은 Root가 조정).

## 목표
핵심 화면(홈, 오늘의 질문, 답변 작성, 아카이브)에 세피아 종이 질감 테마를 적용하고, 사용자가 글자 크기를 조절할 수 있게 한다.

## 범위
- **테마 한 곳**: 색, 글꼴 이름, 질감 강도를 상수로 모은 테마 파일. 위젯은 이 테마만 참조한다(글꼴·다크 모드를 나중에 추가하기 쉽게).
- **글꼴**: 후보 3~4개(한글 손글씨, 단정한 느낌, OFL 등 상업 이용 가능 라이선스를 각각 직접 확인)를 앱 안 비교 화면으로 만든다(18sp 이상 본문, 숫자, 긴 문단, 최대 배율). 실행 결과 스크린샷과 함께 추천 1개와 근거를 PR에 적는다. 최종 선택은 오너가 하므로 선택 전까지는 후보 중 가장 가독성이 좋은 것을 임시 적용한다. 글꼴 파일은 앱에 포함(assets)하고 런타임 다운로드를 쓰지 않는다.
- **배경**: 중앙은 밝은 종이색, 테두리는 세피아인 방사형 그라데이션 + 코드로 만든 은은한 노이즈. 강도·색은 상수. 스크롤과 입력 성능에 영향이 없어야 한다(화면당 한 번 그리고 캐시).
- **하단 탭**: 홈·목록·캘린더·설정 4개(`go_router`의 shell 구조). 목록=지난 질문 타임라인(archive 작업이 채움), 캘린더=자리만(준비 중 화면), 설정=글자 크기 항목과 오픈소스 라이선스 화면 진입.
- **글자 크기 조절**: 앱 루트에서 텍스트 배율을 적용(시스템 배율 × 사용자 배율, 상한 설정). 두 손가락 확대 제스처가 임계값(예: 배율 변화 25% 이상, 0.3초 이상 유지)을 넘으면 "화면을 확대하시겠습니까?"와 슬라이더(단계 100/115/130/150/170%)를 담은 시트를 띄운다. 스크롤·한 손가락 동작과 충돌하지 않아야 한다. 설정 화면에도 같은 조절 항목. 배율은 기기에 저장.
- **출처 표기**: 오픈소스 라이선스 화면(Flutter의 패키지 라이선스 자동 수집 + 글꼴 라이선스 등록), `docs/THIRD_PARTY_NOTICES.md`에 글꼴 이름·저작권자·라이선스·출처 URL.
- 핵심 화면 4개를 새 테마로 교체. 기능·API 호출은 바꾸지 않는다.

## 범위 밖
다크 모드, 글꼴 선택 설정, 애니메이션·햅틱, 일러스트·캐릭터, 캘린더 화면 내용, 앱 아이콘·로고, 외부 서비스의 캐릭터·아이콘·문구·배치 복제.

## 수용 기준 (테스트로 표현)
- [ ] 위젯 테스트: 본문 글자 크기 18sp 이상, 터치 대상 48dp 이상(주요 버튼 56dp), 본문 글자와 배경의 대비 4.5:1 이상(테마 색 조합을 계산하는 단위 테스트).
- [ ] 배율 100%와 최대 배율에서 핵심 4개 화면이 오버플로 없이 그려진다(골든 또는 위젯 테스트).
- [ ] 두 손가락 확대가 임계값 미만이면 시트가 뜨지 않고, 임계값 이상이면 뜬다. 슬라이더 조작이 배율을 바꾸고 저장·복원된다.
- [ ] 키가 없는 환경에서도 `flutter analyze`, `flutter test`가 통과한다. 글꼴 라이선스 항목이 라이선스 화면에 나온다.
- [ ] 외부 서비스의 에셋·캐릭터가 저장소에 없다(파일 목록 확인).
