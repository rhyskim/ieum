# ADR-0009: 디자인 시스템(종이 질감 테마)과 글자 크기 조절

- 상태: 확정
- 날짜: 2026-11-23

## 맥락
기본 Material 테마로 만든 화면들을 "추억을 기록한다"는 앱의 성격에 맞는 시각 언어로 바꾼다. 주 사용자인 부모 세대의 가독성(본문 18sp 이상, 대비 4.5:1, 터치 48dp 이상, CLAUDE.md §5)이 장식보다 우선한다. 외부 서비스의 화면은 분위기만 참고하고 캐릭터·아이콘·문구·배치를 복제하지 않는다.

## 결정
1. **글꼴**: 한글 손글씨 계열 한 가지를 제목과 본문에 통일해서 쓴다. 단정하고 가독성이 좋은 OFL 등 상업 이용이 가능한 글꼴만 후보로 한다. 후보 3~4개를 앱 안의 비교 화면(18sp 이상 본문, 숫자, 긴 문단)으로 확인해 고르고, 가독성이 부족하면 제목에만 손글씨, 본문에는 가독성이 좋은 글꼴을 쓰는 조합으로 바꾼다. 글꼴 이름은 테마 한 곳에서만 참조해 이후 글꼴 선택 설정을 추가하기 쉽게 한다(아이디어 노트).
2. **색과 질감**: 세피아 톤. 중앙은 밝은 종이색, 테두리로 갈수록 세피아로 바래는 방사형 그라데이션을 배경에 쓴다. 질감은 이미지 파일이 아니라 코드로 만든 은은한 노이즈로 표현해 용량과 저작권 부담을 없앤다(결과를 보고 조정할 수 있게 강도와 색을 상수로 분리). 바랜 색은 배경과 장식에만 쓰고 본문 글자는 대비 4.5:1 이상을 유지한다. 다크 모드는 이번 범위가 아니다.
3. **적용 범위**: 핵심 화면(홈, 오늘의 질문, 답변 작성, 아카이브)부터 단계적으로 적용한다. 하단 탭은 홈·목록·캘린더·설정 4개로 한다. 캘린더 탭은 자리만 두고 내용은 별도 작업으로 정한다.
4. **일러스트·캐릭터**: 이번 범위에서 만들지 않는다. 단순한 선 아이콘(한글 라벨 병기)만 쓴다.
5. **글자 크기 조절**: 앱 전체 글자 배율을 사용자가 정한다. 두 손가락 확대(pinch) 동작이 일정 감도(임계값과 지속 시간 이상)를 넘으면 "화면을 확대하시겠습니까?"와 가로 막대(슬라이더)를 보여 주고, 막대로 글자 크기를 단계별(예: 100/115/130/150/170%)로 조절한다. 오작동 방지를 위해 한 번의 짧은 접촉은 무시한다. 제스처를 모르는 사용자를 위해 설정 화면에도 같은 조절 항목을 둔다. 배율은 기기에 저장하고 시스템 글자 크기 설정과 곱해 적용하되 상한을 둔다. 모든 핵심 화면은 최대 배율에서 잘림·겹침이 없어야 한다.
6. **출처 표기**: 사용하는 글꼴과 에셋의 라이선스 전문을 앱 안 "오픈소스 라이선스" 화면에서 볼 수 있게 하고(패키지 라이선스는 Flutter가 자동 수집, 글꼴 라이선스는 등록), 저장소에도 `docs/THIRD_PARTY_NOTICES.md`로 남긴다.
7. 애니메이션·햅틱은 V2로 미룬다(아이디어 노트).

## 근거와 트레이드오프
- **손글씨 통일의 위험**: 손글씨 글꼴은 획이 가늘거나 글자 모양이 불규칙해 작은 글씨나 긴 문단에서 가독성이 떨어질 수 있다. 그래서 후보를 실제 화면으로 비교하고, 기준 미달이면 제목·본문을 분리하는 대안을 열어 둔다.
- **코드 생성 질감**: 이미지 질감보다 표현이 단순하지만 용량·저작권·해상도 문제가 없고 조정이 쉽다.
- **확대 제스처의 충돌**: 스크롤 영역 안의 두 손가락 동작과 겹칠 수 있고 발견하기 어렵다. 감도 임계값과 설정 화면의 대체 경로로 보완한다.
- **글자 크기 상한**: 배율이 커질수록 레이아웃이 깨지므로 상한과 최대 배율 테스트가 필요하다.
