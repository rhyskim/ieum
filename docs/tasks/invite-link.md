# Task: invite-link — 보류 (다음 개발 사항)

- 상태: **보류**. 출시 후 서비스 이용률을 보고 도메인 구매와 함께 착수 여부를 결정한다(2026-11-17 결정).
- 선행: `group-core` 머지. 외부 준비: https 도메인, Apple Developer 설정, Android 서명 인증서 지문.

## 확정된 사양 (ADR-0003)
- 링크는 6자리 코드와 별개의 자격증명이다. 추측 불가능한 긴 토큰(128비트 이상)을 쓰고, **유효기간 18시간, 1회용**, 입장 시 **방장 승인 생략**(방장이 강퇴할 수 있음).
- 링크를 여는 것(GET)으로는 소진하지 않는다. 카카오톡이 미리보기를 위해 링크를 먼저 열어 보기 때문이다. 로그인한 앱이 보내는 수락 요청(POST)에서만 소진한다.
- 방장에게 "링크로 입장했어요" 알림을 보낸다.

## 구현 시 결정해야 할 것
- 유니버설 링크(iOS)/앱 링크(Android) 연결 파일 호스팅, 앱 미설치 시 스토어 안내, 설치 후 초대 이어가기(디퍼드 딥링크: 외부 서비스 vs 직접 구현, 종료된 서비스 여부는 시점에 공식 문서 확인).
- `invite_links` 테이블, 링크 발급·수락 API, 만료·소진 후 안내 화면.
