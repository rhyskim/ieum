# 아이디어 노트

구현 여부를 아직 정하지 않은 아이디어를 모아 둔다. 결정되면 ADR(`docs/adr`)과 작업지시서(`docs/tasks`)로 옮기고 여기서는 상태만 바꾼다.

| 상태 | 뜻 |
|---|---|
| 검토 중 | 방향을 고민하는 중 |
| 보류 | 필요가 확인될 때까지 미룸 |
| 채택 | ADR/작업지시서로 옮김 |

## 디자인·경험
| 아이디어 | 상태 | 메모 |
|---|---|---|
| 글꼴 선택 설정 | 검토 중 | 앱에서 한글 손글씨 글꼴을 고를 수 있게 한다. 글꼴 이름을 한 곳에서 참조하도록 테마를 설계해 두어 추가 비용을 줄인다. |
| 다크 모드 | 검토 중 | 종이 질감 테마와 어울리는 어두운 색 구성이 필요하다. 접근성 대비 기준(4.5:1)을 함께 검증해야 한다. |
| 애니메이션·햅틱 | 채택(V2) | 질문이 도착하는 순간 등. 핵심 화면 구현 이후에 추가한다. |
| 캐릭터와 상호작용·성장 | 검토 중 | 캐릭터를 둘지, 성장 요소를 둘지 정해지지 않았다. 외부 서비스의 캐릭터·아이콘은 사용하지 않고 고유한 모티프를 만든다. |
| 일러스트 세트 | 보류 | 캐릭터 방향이 정해진 뒤 결정한다. 그전에는 단순한 선 아이콘을 쓴다. |
| 캘린더 화면 | 검토 중 | 하단 탭에 자리는 있고, 날짜별 답변 표시 등 상세는 정해지지 않았다. |

## 기능
| 아이디어 | 상태 | 메모 |
|---|---|---|
| 스페셜 데이(멤버가 만든 질문) | 보류 | 그룹원 중 한 명이 만든 질문을 그날의 질문으로 쓴다. 질문 배정 로직과 신고·검수 정책이 필요하다. |
| 링크 초대 | 보류 | 도메인과 유니버설 링크가 필요하다. 출시 후 이용률을 보고 결정한다(`docs/tasks/invite-link.md`). |
| 알림 설정(끄기·시간 변경) | 검토 중 | 개인별 알림 시각과 알림 끄기. 컬럼은 있고 화면과 로직이 없다. |
| 음성 답변의 텍스트 변환 검증 | 검토 중 | 변환을 앱에서 할지 서버에서 할지에 따라 최소 글자 수 규칙의 신뢰 수준이 달라진다. |
