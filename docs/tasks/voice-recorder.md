# Task: voice-recorder (원본 음성 녹음기, 3분 제한, 전화 유도 모달)

- 브랜치: `feat/voice-recorder` / worktree: `.worktrees/voice-recorder`
- 대상: mobile 전용(서버 업로드 연동은 설계 확정 후 별도 작업)
- 선행: answer(머지됨)

## 목표
부모님이 키보드 없이 자기 목소리를 녹음하고, 3분에 도달해도 파일이 유실되지 않으며, 이야기가 길어졌을 때 가족에게 전화를 걸도록 안내하는 녹음 화면을 만든다. 이 작업은 기기 안에서 끝나고 서버로 보내지 않는다.

## 범위
- 녹음 모듈(`record`): AAC-LC `.m4a`, 64kbps, 모노. 시작·일시정지·이어서·완료·다시 녹음, 경과 시간과 파형 애니메이션 표시. 녹음 파일은 앱 전용 임시 폴더에 저장.
- 시간 규칙: 150초에 타이머 색상 변경과 "30초 뒤 녹음이 마무리됩니다" 안내, 180초에 녹음을 안전하게 자동 완료(파일 보존 보장)하고 즉시 전화 유도 모달을 띄운다. 모달에는 가족 호칭이 들어간 안내 문구, "지금 전화 걸기"(`url_launcher`의 `tel:`, 번호가 없으면 비활성+이유), "녹음한 3분 먼저 등록하기"(이번 범위에서는 완료 상태로 돌아가기) 버튼. 에러 대신 안내로 처리한다(CLAUDE.md §5).
- 마이크 권한: 거부·영구 거부·다른 앱이 마이크 사용 중·저장 공간 부족·통화 중 인터럽트(`audio_session`)를 각각 안내하고 이미 녹음된 부분은 보존한다. 앱이 백그라운드로 가면 일시정지.
- 녹음 직후 미리 듣기(`just_audio`): 재생/정지, 탐색 바. 업로드가 없으므로 "등록" 버튼은 이번 범위에서 비활성 자리표시이거나 임시 파일 보존까지만 한다(PR에 명시).
- 진입: 답변 작성 화면에 "목소리로 답하기" 진입 버튼만 추가(다른 화면 수정 최소화, voice-device 작업이 같은 화면을 만지므로 충돌을 줄이기 위해 독립 위젯과 라우트로 만든다).
- 접근성 불변식: 본문 18sp 이상, 터치 48dp 이상(주요 56dp), 아이콘 버튼에 한글 라벨, 대비 4.5:1.

## 범위 밖
업로드(S3 Presigned)·답변 저장 연동·재생기(다운로드 URL)·보관 만료·음성 리액션(설계 확정 후 별도 작업), iOS 실행, 디자인 톤 변경.

## 수용 기준 (테스트로 표현)
- [ ] 가짜 녹음기와 가짜 시계로: 150초에 경고 상태, 180초에 자동 완료되고 파일 경로가 보존되며 전화 유도 모달이 한 번만 뜬다.
- [ ] 일시정지 시간은 경과 시간에 포함되지 않고, 일시정지·이어서·다시 녹음 상태 전이가 올바르다(상태 머신 단위 테스트).
- [ ] 전화 번호가 없으면 "지금 전화 걸기"가 비활성이고 이유가 표시된다. 번호가 있으면 `tel:` 실행이 호출된다.
- [ ] 권한 거부·마이크 사용 중·저장 공간 부족·인터럽트 각각에서 안내가 나오고 이미 녹음된 파일은 삭제되지 않는다.
- [ ] 위젯 테스트로 접근성 불변식(18sp, 48dp/56dp, 한글 라벨)을 확인한다.
- [ ] `flutter analyze`, `flutter test`가 통과한다. 녹음 모듈은 실제 마이크 없이 테스트된다(인터페이스 뒤에 가짜 구현).
