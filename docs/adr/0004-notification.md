# ADR-0004: 푸시 알림(FCM) 발송 방식과 기기 토큰

- 상태: 확정
- 날짜: 2026-11-18

## 맥락
group-core의 입장 요청을 방장에게 푸시로 알리고, 승인·거절 결과를 요청자에게 알린다. `user_devices`는 `UNIQUE(user_id, fcm_token)`이라 같은 토큰이 서로 다른 사용자 행에 존재할 수 있다. 푸시는 보조 채널이고 앱 안의 승인 대기 목록이 기준이다.

## 최종 결정 (2026-11-18)
위 "확정 대기" 1·2번을 그대로 채택한다. 기기 토큰의 `UNIQUE(fcm_token)` 스키마 변경(Flyway)을 승인한다. 마이그레이션 번호는 먼저 머지되는 쪽(notification 또는 account)이 V4를 쓰고 나중 쪽이 올린다. 기존 `UNIQUE(user_id, fcm_token)`은 새 제약으로 대체한다(현재 등록 API가 없어 중복 데이터는 없다).
