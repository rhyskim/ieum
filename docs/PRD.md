# PRD (제품 요구사항 정의서) — 이음 (Ieum)

- **문서 버전**: v1.0.0
- **서비스 명칭**: 이음 (Ieum, 잠정 확정)
- **출시 형태**: 모바일 네이티브 앱 (iOS / Android — Flutter 기반)
- **타깃 리전**: 대한민국 (서울 리전, KST 기준 운영)

---

## 1. 제품 비전 및 배경

### 1.1 제품 한 줄 정의
부모와 자식이 **하루에 하나의 질문**에 각자 답하고, 서로의 텍스트와 **실제 목소리(원본 녹음)**를 확인하며 가족의 역사와 감정을 기록·보존하는 양방향 가족 소통 앱.

### 1.2 기획 의도 및 핵심 가치
1. **양방향 소통의 회복**: 자식이 부모를 일방적으로 취재하는 형태가 아니라, 같은 질문(예: *"가장 기억에 남는 우리 가족 여행은 언제인가요?"*)에 부모와 자식이 각자의 시선으로 답하며 서로를 새롭게 알아갑니다.
2. **부모 세대에게 장벽 없는 음성 경험**: 글자 입력이 힘들고 작은 글씨가 불편한 50~70대 부모님을 위해 질문 읽어주기(TTS), 말로 글쓰기(STT), 그리고 **목소리 원본 그대로 남기기**를 기본 제공합니다.
3. **목소리 유산(Voice Legacy)과 현실 대화의 연결**: 텍스트만으로는 전해지지 않는 부모님의 숨소리, 억양, 웃음소리를 원본 오디오로 전달하되, 이야기가 3분을 넘어갈 만큼 깊어지면 앱에 머무는 대신 **직접 전화를 걸어 대화하도록 연결**합니다.

## 2. 타깃 페르소나 (Personas)

### 페르소나 A: 자식 (개설자 및 초대 주체, 20~40대)
- **특징**: 부모님과 떨어져 살거나 바쁜 일상 때문에 용건 위주의 짧은 통화만 하는 것에 아쉬움을 느낌. 나중에 부모님의 목소리와 이야기를 남기고 싶어 함.
- **역할**: 앱을 발견해 설치하고 가족 방을 개설한 뒤 카카오톡/초대코드로 부모님을 초대함. 친정 방, 시댁 방 등 **여러 가족 그룹에 동시에 참여**할 수 있음. 향후 프리미엄 부가 기능 결제 주체.

### 페르소나 B: 부모 (초대받는 참여자, 50~70대)
- **특징**: 카카오톡과 네이버는 익숙하지만 새로운 앱 가입이나 복잡한 메뉴 탐색에 피로감을 느낌. 스마트폰 키보드 오타가 잦아 긴 글 작성을 부담스러워하지만 음성 대화에는 친숙함.
- **역할**: 자녀가 보낸 카카오톡 링크나 6자리 숫자 코드로 간편하게 입장. 버튼을 눌러 질문을 귀로 듣고(TTS), 마이크로 이야기하여(STT 및 원본 녹음) 답변을 남김.

## 3. 상세 기능 요구사항 (Functional Requirements)

### FR-1. 회원 가입 및 소셜 인증
- **FR-1.1 소셜 로그인**:
  - **카카오 로그인 (1순위)**: 5070 부모 세대 및 전 연령대 기본 로그인 수단.
  - **네이버 로그인**: 카카오 미사용자 및 부모 세대 보조 수단.
  - **Apple 로그인**: iOS 사용자 및 App Store 심사 필수 요건 대응.
- **FR-1.2 초기 프로필 및 접근성 자동 설정**:
  - 가입 시 입력 항목: 이름(또는 닉네임), 주 사용 역할 선택(`부모님` / `자녀`), 전화번호(선택 입력 — 가족 간 3분 초과 통화 연결 기능에 활용).
  - 사용자가 `부모님` 역할을 선택하면 즉시 **부모 세대 접근성 모드(글씨 크기 '크게', 고대비 UI)**가 기본값으로 활성화됨.

### FR-2. 다중 가족 그룹 및 초대 시스템 (썸원 스타일)
- **FR-2.1 다중 그룹 소속 (N:M 구조)**:
  - 한 사용자는 개수 제한 없이 여러 가족 그룹에 소속될 수 있음 (예: `우리집 단톡방(엄마·아빠·나)`, `시댁 가족방(어머님·아버님·남편·나)`).
  - 앱 상단 앱바에서 드롭다운 또는 탭으로 현재 활성 그룹을 즉시 전환할 수 있어야 함.
- **FR-2.2 유연한 인원 구성 (2~N인)**:
  - 최소 2인(예: 엄마+나)부터 N인(예: 엄마+아빠+언니+나)까지 제한 없이 참여 가능.
  - 그룹 내에서 각 멤버는 자신의 **그룹 내 역할(`PARENT` / `CHILD`)**과 **가족 호칭(예: `엄마`, `아빠`, `큰딸`, `막내아들`)**을 설정함.
- **FR-2.3 초대 방식 (2가지 모두 지원)**:
  1. **6자리 숫자 초대코드**: 썸원(Someone)과 유사하게 큼직한 6자리 숫자 코드(예: `842910`)를 화면에 띄우고, 초대받는 부모님이 숫자 키패드만으로 간편하게 입력하면 즉시 매칭.
  2. **카카오톡 공유 (딥링크 연동)**: `[카카오톡으로 부모님 초대하기]` 버튼 클릭 시 초대 메시지와 딥링크(`ieum://invite?code=842910`) 발송 → 앱 설치 후 실행 시 코드가 자동 입력되어 즉시 그룹 가입 완료.

### FR-3. 일일 질문 배정 및 알림 스케줄링
- **FR-3.1 질문 생성 기준 시각 (고정)**:
  - 모든 가족 그룹의 새로운 질문은 매일 **오후 7시 정각(19:00 KST)**을 기준으로 배정됨.
- **FR-3.2 푸시 알림 시각 (그룹 기본값 + 개인별 커스텀)**:
  - **Default**: 모든 그룹 멤버는 기본적으로 질문 생성 시각인 **오후 7시(19:00 KST)**에 오늘의 질문 도착 푸시 알림을 받음.
  - **Custom**: 각 사용자는 그룹별로 자신이 푸시 알림을 받고 싶은 시각(예: 엄마는 저녁 7시, 야근이 잦은 자식은 밤 10시, 아침형 아버지는 다음 날 오전 8시)을 개별 설정할 수 있음.

### FR-4. 멀티모달 답변 작성 (텍스트 + STT + 원본 음성 녹음)
사용자는 하나의 질문에 대해 아래 방식을 자유롭게 조합하여 답변할 수 있습니다.

- **FR-4.1 질문 음성 낭독 (TTS)**:
  - 질문 카드 우측 상단의 큼직한 `[🔊 질문 듣기]` 버튼을 누르면 온디바이스 TTS 엔진이 질문을 읽어줌. (한 번 더 누르면 느린 속도 `0.85x`로 재생)
- **FR-4.2 답변 입력 방식**:
  1. **일반 텍스트 입력**: 키보드로 직접 작성.
  2. **AI 음성→텍스트 변환 (STT)**: 마이크 버튼을 누르고 말하면 실시간으로 음성이 텍스트로 변환되어 입력창에 채워짐. 변환 후 오타를 키보드로 수정 가능.
  3. **원본 음성 녹음 및 그대로 전달 (Original Voice)**:
     - STT로 변환된 텍스트뿐만 아니라, **실제 녹음된 부모님/자식의 목소리 파일(`.m4a`) 원본 그 자체**를 서버에 업로드하여 가족에게 전달함.
     - 사용자가 `[🎤 목소리로 답하기]`를 누르면 **원본 음성 녹음과 STT 텍스트 변환이 동시에 진행**되어, 상대방은 눈으로 텍스트를 읽으면서 동시에 귀로 실제 목소리 원음을 들을 수 있음(원할 경우 텍스트 없이 원본 음성만 등록하는 것도 가능).
- **FR-4.3 최대 녹음 시간 제한(3분) 및 감성 전화 유도 UX**:
  - **포맷 및 용량 기준**: `AAC / .m4a (64kbps, Mono)` — 1분당 약 480~500KB, 3분 최대 약 1.5MB.
  - **시간 제한**: 1회 답변당 원본 음성 녹음은 **최대 3분(180초)**으로 제한.
  - **2분 30초 예고**: 녹음 시간이 2분 30초를 넘으면 남은 시간 카운트다운이 부드럽게 강조됨.
  - **3분 도달 시 감성 안내 모달 (핵심 UX)**:
    - 3분이 되는 순간 녹음은 안전하게 자동 종료·저장되며, 화면에 따뜻한 일러스트와 함께 아래 안내 모달이 표시됨:
      > **💌 나누고 싶은 이야기가 참 많은 밤이네요**
      > *"오늘은 이 질문에 대해 나누고 싶은 이야기가 많은가 봐요. 오늘 밤은 **[가족 호칭(예: 엄마/딸)]**에게 직접 전화해서 목소리를 들으며 이 이야기를 나눠보는 것은 어떨까요?"*
    - **제공 버튼**:
      - `[📞 OO에게 지금 전화 걸기]` (가족 프로필에 등록된 전화번호로 스마트폰 다이얼 즉시 연결)
      - `[방금 녹음한 3분 답변 먼저 올리기]` (3분까지 녹음된 음성을 유실 없이 그대로 답변으로 등록)

### FR-5. 답변 공개 규칙 및 미답변 넛지(Nudge) 정책
- **FR-5.1 전원 답변 시 즉시 공개**:
  - 그룹 내 모든 활성 멤버가 답변을 제출하면 **즉시 잠금이 해제(`REVEALED_ALL`)**되고, 전원에게 *"가족 모두가 답변을 마쳤어요! 서로의 마음과 목소리를 확인해 보세요"* 푸시 알림 발송.
- **FR-5.2 타임아웃 자동 공개 (새 질문 오기 2시간 전)**:
  - 3인 이상의 가족 방 등에서 일부 멤버가 바빠서 답변하지 못하더라도, **다음 날 새 질문이 오기 2시간 전인 오후 5시(17:00 KST, 질문 생성 후 22시간 경과 시점)**가 되면 **답변을 완료한 멤버들끼리 먼저 답변이 자동 공개(`REVEALED_TIMEOUT`)**됨.
  - 아직 답변하지 않은 멤버는 오후 5시 이후라도 자신의 답변을 뒤늦게 작성하면 즉시 다른 가족의 답변을 열람할 수 있음.
- **FR-5.3 미답변자 전용 알림 서비스 (2단계 넛지)**:
  1. **가족 선답변 넛지**: 그룹 내 첫 번째(또는 다른) 멤버가 답변을 등록했을 때, **아직 답변하지 않은 멤버에게만** *"방금 [엄마]님이 오늘의 질문에 답을 남겼어요! 답변을 남기면 서로의 이야기를 들을 수 있어요"* 푸시 발송.
  2. **마감 2시간 전 리마인드 (익일 15:00 KST)**: 자동 공개 시각(17:00 KST) 2시간 전인 **오후 3시(15:00 KST)** 시점에 **여전히 답변하지 않은 멤버에 한해** *"오늘의 질문이 2시간 뒤에 공개됩니다. 잊지 않고 짧은 목소리라도 남겨볼까요?"* 리마인드 푸시 발송.

### FR-6. 리액션 및 아카이브 (타임라인)
- **FR-6.1 리액션**: 공개된 가족의 답변에 5종의 감정 이모지(사랑해요, 감동이에요, 고마워요, 웃겨요, 안아줄래요) 또는 **30초 이내의 짧은 음성 리액션**을 남길 수 있음.
- **FR-6.2 아카이브**: 지난 문답을 최신순/오래된순/카테고리별(추억, 일상, 가치관, 감사 등) 및 '음성이 있는 답변만 모아보기' 필터로 열람 가능.

## 4. 음성 데이터 수명주기(Lifecycle) 및 무료/유료(Premium) 정책

### 4.1 서버 부담 최소화를 위한 주기적 오디오 정리 계획
- **텍스트 데이터**: DB 용량 부담이 극히 적으므로 무료/유료 관계없이 **영구 보관**.
- **원본 음성 파일(`.m4a`) 보관 주기**:
  - **기본(무료 플랜) 서버 보관 기간: 30일**
  - 답변 등록일로부터 **30일이 경과한 원본 오디오 파일은 S3 Object Lifecycle 정책에 의해 서버에서 자동 삭제**되어 스토리지 비용이 누적되지 않도록 통제함.
- **사용자 보호 장치 (삭제 전 알림 & 로컬 다운로드)**:
  1. **삭제 7일 전(23일 차) 사전 안내**: *"일주일 뒤 [날짜] 문답의 음성 파일이 서버 보관함에서 정리됩니다. 소중한 목소리를 내 휴대폰에 저장해 두세요."* 알림 제공.
  2. **내 기기에 영구 저장(로컬 다운로드)**: 사용자는 언제든(30일 만료 전) 가족의 원본 음성 파일을 **내 스마트폰 내부 저장소에 다운로드**할 수 있음. 다운로드된 파일은 서버에서 30일 뒤 삭제되더라도 사용자의 폰에서 영구히 재생 가능.

### 4.2 v1 무료 배포 및 향후 유료화(Premium) 전환 설계
- **v1 정책**: 초기 사용자 확보 및 포트폴리오 완성을 위해 **모든 기본 기능(원본 음성 녹음/전달 포함)을 100% 무료로 제공**함.
- **향후 유료화(프리미엄 요금제 / 가족 패스) 전환 후보 기능**:
  1. **원본 음성 전달 기능 자체의 유료화 또는 월간 횟수 제한 해제**: 코드 레벨에서 `EntitlementPolicy.canAttachOriginalVoice` 플래그로 제어하여 앱 재심사 없이도 정책 변경이나 유료 플랜 연동이 가능하도록 설계.
  2. **서버 클라우드 음성 영구 보관**: 30일 자동 삭제 제한을 해제하고 서버에서 무제한 보관.
  3. **최대 녹음 시간 확장**: 3분 → 10분 확장.
  4. **고품질 클라우드 AI STT/TTS**: 온디바이스 엔진 대신 OpenAI Whisper / CLOVA 고품질 엔진 제공.
  5. **연말 가족 문답 오디오북 & 실물 책자(PDF) 출판**.

## 5. 비기능 요구사항 및 국내 개인정보보호법 체크리스트

### 5.1 부모 세대 접근성 (Accessibility) 기준
- **타이포그래피**: 부모 모드 활성화 시 본문 최소 `20sp`, 질문 제목 `24sp`, 줄간격 `1.5` 이상.
- **터치 영역**: 모든 버튼 높이 최소 `56dp` 이상, 주요 행동 버튼은 화면 하단 전체 너비(Full-width) 배치.
- **3탭 완결 원칙**: 푸시 알림 클릭 → `[🔊 질문 듣기]` (1탭) → `[🎤 목소리로 답하기]` (2탭) → `[답변 완료]` (3탭) 이내에 당일 루프가 끝나야 함.

### 5.2 개인정보 및 음성 데이터 법적 체크리스트 (국내 개인정보보호법 준수)
음성 데이터는 개인을 식별할 수 있는 생체·민감 성격의 개인정보로 해석될 여지가 있으므로 아래 체크리스트를 온보딩 및 설정에 반드시 반영합니다.

- [ ] **[필수] 개인정보 수집·이용 동의**: 소셜 식별자, 이름/닉네임, 이메일, (선택) 전화번호 수집 고지.
- [ ] **[필수/별도] 음성 데이터 녹음·전송·보관 동의**:
  - 수집 목적: 가족 그룹 내 원본 음성 전달 및 STT 텍스트 변환.
  - 보유 및 이용 기간: **서버 업로드 후 30일 보관 후 자동 파기** (단, 프리미엄 영구 보관 선택 시 탈퇴 시까지).
  - 제3자 제공 여부: 가족 그룹 내 승인된 멤버에게만 열람 권한 부여(외부 공개 없음).
- [ ] **부모 본인 동의 UX**: 자식이 부모를 초대하더라도, 부모 본인이 최초 앱 진입 시 큰 글씨로 요약된 **"내 목소리가 가족 방에 공유되며 30일간 서버에 보관됩니다"** 안내에 직접 `[동의하고 시작하기]`를 누르도록 구성.
- [ ] **그룹 탈퇴 및 데이터 삭제권 보장**:
  - 그룹 탈퇴 시: 본인이 작성한 답변 및 S3에 저장된 원본 음성 파일을 **즉시 삭제**할지, 가족을 위해 남겨둘지 본인이 선택 가능하도록 옵션 제공.
  - 회원 탈퇴 시: 즉시 S3 내 해당 유저의 모든 `.m4a` 객체를 삭제(`DeleteObjects`)하고 DB 레코드를 파기.
