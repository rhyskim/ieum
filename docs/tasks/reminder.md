# Task: reminder (15시 리마인드, 17시 공개 푸시)

- 브랜치: `feat/reminder` / worktree: `.worktrees/reminder`
- 대상: backend 중심 + mobile은 푸시 탭 이동 경로만
- 선행: answer, archive(머지됨). 푸시는 ADR-0004 이벤트 패턴을 재사용한다.

## 목표
답변하지 않은 멤버에게 마감 2시간 전(15:00 KST) 리마인드를 한 번만 보내고, 17:00에 시간 초과 공개가 일어나면 가족에게 한 번만 알린다. 서버가 여러 대이거나 재시작돼도 알림은 중복되지 않는다.

## 범위
- **15시 리마인드**: 15:00~16:55(KST) 5분마다 도는 보정형 작업(ADR-0006과 같은 방식). 대상은 `LOCKED`이면서 자동 공개 시각(`auto_reveal_at`)이 오늘 17:00이고 `reminder_sent=false`인 질문. `UPDATE daily_questions SET reminder_sent=true WHERE id=? AND reminder_sent=false`가 1행일 때만 해당 질문의 **아직 답하지 않은 유효 멤버**(아무도 답하지 않았다면 모든 유효 멤버)에게 푸시를 발행한다. 15시 문구는 고정 문구이고 data는 `type`·`groupId`만 쓴다. 서버가 15시에 꺼져 있다 16시에 켜져도 다음 실행이 보낸다. 17시 이후에는 보내지 않는다.
- **17시 공개**: 17:00~17:55 5분마다 도는 작업이 `auto_reveal_at <= now`이고 답변이 1건 이상인 `LOCKED` 질문을 id 오름차순으로 `REVEALED_TIMEOUT` 전환한다(기존 `RevealEvaluator`의 조건부 UPDATE 재사용, 락 순서는 ADR-0007 결정 9를 따른다). 전환이 1행일 때만 푸시하며 문구는 수신자마다 다르다(수신자가 정한 가족 호칭 `member_aliases`를 쓰고, 호칭이 없으면 멤버 표시 이름 규칙(DisplayNames)을 따른다). 답한 멤버에게는 다른 답변자 한 명(가장 먼저 답한 사람)의 호칭을 넣어 "{호칭}님은 오늘의 질문에 어떤 답을 했을까요?", 다른 답변자가 없으면 "가족의 답변이 공개됐어요". 답하지 않은 멤버에게는 답변한 사람들의 호칭을 최대 3명까지 넣어 "{호칭}, {호칭}님은 오늘의 질문에 답을 남겼어요. {수신자 호칭이 아닌 수신자 본인의 이름}님도 답을 남겨보시는 게 어떨까요?"(3명을 넘으면 "{호칭}, {호칭}, {호칭}님 외 N명은 …"). 답변이 0건이면 LOCKED를 유지하고 공개 푸시는 보내지 않는다.
- 조회 시점의 지연 전환(기존)과 이 작업은 같은 조건부 UPDATE를 쓰므로 어느 쪽이 먼저 전환하든 푸시는 전환한 쪽에서만 한 번 나간다. 조회가 먼저 전환한 경우 푸시가 누락되지 않도록 전환 지점을 한 곳으로 모으거나 지연 전환도 같은 알림 경로를 타게 하라(설계를 구현 전에 Root에 한 번 요약한다).
- 모바일: `push_routing`에 리마인드·공개 알림 type을 오늘의 질문 화면으로 연결.
- ShedLock 적용, 테스트에서는 스케줄러를 끄는 설정 재사용.

## 범위 밖
개인별 알림 시각·끄기(Phase 3 알림 설정), 알림함 화면, 음성 관련 알림.

## 수용 기준 (테스트로 표현)
- [ ] 같은 질문에 대해 작업을 여러 번·동시에 실행해도 리마인드 푸시는 대상 멤버당 1회(서버 2대 동시 실행 테스트 포함).
- [ ] 이미 답한 멤버·탈퇴 유예·탈퇴 멤버에게는 리마인드가 가지 않는다.
- [ ] 15시에 서버가 꺼져 있다 16시에 켜지는 상황(시각 주입)에서 리마인드가 한 번 나가고, 17시 이후에는 나가지 않는다.
- [ ] 17시 전환 작업과 조회 시 지연 전환이 경쟁해도 공개 푸시는 1회이고, 어느 쪽이 전환해도 푸시가 누락되지 않는다.
- [ ] 답변 0건이면 전환·푸시가 없고 LOCKED가 유지된다. 전원 답변으로 이미 `REVEALED_ALL`인 질문에는 보내지 않는다.
- [ ] 17시 공개 푸시 문구가 수신자별로 다르게 만들어지고(답한 멤버/답하지 않은 멤버/다른 답변자 없음), 호칭은 수신자가 정한 것이며 호칭이 없으면 표시 이름 규칙을 따른다. 3명 초과 시 "외 N명". 답변 내용은 문구와 data에 들어가지 않는다.
- [ ] 푸시 data는 `type`·`groupId`만이고, 푸시 탭이 오늘의 질문 화면으로 이동한다(모바일 라우팅 테스트).
- [ ] 호칭에 줄바꿈·매우 긴 문자열이 있어도 문구 길이가 제한된다.
